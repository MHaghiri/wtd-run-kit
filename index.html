    What you get

    Real outputs of the kit's scripts. These come from the MODFLOW 6 kit run on synthetic test terrain, so they show the format, not results for a real place.

    Running a kit

    The same three commands for every model. Each kit's README adds model-specific steps.

    Set up

    conda env create -f environment.yml
conda activate wtd-<model>

    Get WTD

    # published results → your box
python clip_wtd.py --file <product>
# or run the model (see README)

    Plot & compare

    python plot_wtd.py outputs/wtd_X.tif
python compare_wtd.py A.tif B.tif
