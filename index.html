WTD Run Kit

Pick a region, pick a groundwater model, and download a ready-to-run package that computes water table depth (WTD) on your own machine.

1 Choose a region

Draw a rectangle on the map (square tool, top-left), or type the bounds.

2 Choose a model

You'll download the continent file once (link in the package README); the script clips it to your box.

3 Download the package

You get a zip with an environment file, run scripts, a plotting script and a README with step-by-step instructions.
